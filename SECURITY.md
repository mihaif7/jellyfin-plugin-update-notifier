# Security policy

## Supported versions

The most recent release is the only supported version. Fixes are shipped as a new release rather than backported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately rather than opening a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/mihaif7/jellyfin-plugin-updatenotifier/security/advisories/new) for this repository. Include the affected version, a description of the issue, and the steps to reproduce it.

You can expect an initial response within a few days. Once a fix is available it is published as a new release, and the report is credited unless you ask otherwise.
